# stuntkey (npm)

Keep your API keys out of your AI's environment: the key never enters it when used through the broker.

```
npx stuntkey start --simple
```

This package runs the Python program stuntkey. It needs Python 3.10 or newer:
if it is missing, it says so - install it from https://www.python.org and run
again. Full guide: https://github.com/calasdan-sketch/stuntkey
