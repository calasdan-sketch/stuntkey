    Add a key

    Four steps. You never type your key into this page.

    1. Say which service.

      For example OpenAI, GitHub or Stripe. Type it here and the command below updates.


      Letters and numbers only.

    2. Copy this command and paste it into a terminal.
      stuntkey get openai

    3. Follow the prompts.

      StuntKey opens the key page for you. Click that site's own Copy button. StuntKey takes the key from your copy, tests it, and locks it in your keychain.

    4. Switch it on, once.

      Run stuntkey setup. It asks once, plugs StuntKey into your AI apps (Claude Code for every folder) and turns on the Claude Code safety check. Then close and reopen the AI app. stuntkey test checks it in one line.

    Safety, in plain words

    What StuntKey does, and what it does not.

    What it does

    • Keeps your real keys in the keychain your computer already has.
    • Lets your AI make calls through the broker, so the key stays out of its environment.
    • With the Claude Code hook, hides a key that shows up in a command's output.
    • Lets you set a daily limit per key, and a stop switch.

    What it does not do

    • It lowers the risk. It cannot make it zero.
    • It cannot stop an AI misusing a key it is allowed to use. Give each key only the permissions it needs.
    • It does not protect against a virus already running as you: anything running as you can read your keychain.
    • Cursor, Codex, Gemini and Claude Desktop have no hook for their file tools, and screenshots and the clipboard are not covered.

    This page

    • Only opens on this computer.
    • Shows names, never secrets.
    • Has no box to type a key into, on purpose.
    • Sends nothing anywhere.

    Leaked a key? Run stuntkey panic openai. It walks you through cancelling it and making a new one.

    Something not working? Run stuntkey status: it shows green, yellow or red for each part. Then stuntkey fix repairs what it can. For the full list of what StuntKey does not cover, run stuntkey limits.
