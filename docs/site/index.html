Your AI uses your keys. The key stays out of its environment.

StuntKey keeps your API keys in your computer's own keychain. Your AI works with a stand-in, a stunt double, and StuntKey adds the real key on the way out.

Why it matters

Keys stay hidden

Used through the broker, the key never enters your AI's environment. A key it does not hold is much harder to leak.

Spending limits

Set a daily limit on each key, and stop everything with one command.

Fix a leak fast

Leaked one? stuntkey panic openai walks you through it, step by step.

Start in one minute

pip install stuntkey
stuntkey start

The second command checks your computer, looks for keys lying around, and tells you what to do next. Full walk-through.

Honest about the limits

StuntKey lowers the risk. It does not remove it. It is beta and has not had an independent security review yet.

It cannot stop an AI misusing a key it is allowed to use, so give each key only the permissions it needs. It does not protect against a virus already running as you: anything running as you can read your keychain. The Claude Code hook blocks common leaks, but Cursor, Codex, Gemini and Claude Desktop have no such hook for their file tools, screenshots and the clipboard are not covered, and code that hides what it does can get past pattern checks. Details: the threat model.

We publish an Agent Leak Benchmark, a set of ways an AI agent can expose a key. Run it yourself with python -m leakbench from the repository.
