Add your first key

About a minute. You never type a key into a web page, and you never paste it into your AI chat.

  1. Install StuntKey.

    You need Python 3.10 or newer. In a terminal:

    pip install stuntkey
  2. Check your computer.

    This looks for keys lying around and says what to do next. It changes nothing.

    stuntkey start
  3. Add the key.

    Swap openai for your service. StuntKey opens that service's key page. Click the site's own Copy button. StuntKey takes the key from your copy, tests it, and locks it in your keychain.

    stuntkey get openai
  4. Switch it on.

    One command plugs StuntKey into your AI apps and turns on the Claude Code safety check. It lists what it will change and asks first. Then restart your AI app.

    stuntkey fix
  5. Check it worked.

    Shows green, yellow or red for each part, and the keys you have saved (names only, never the key). If something is not green, stuntkey fix repairs what it can.

    stuntkey status

Want to see it work first? stuntkey try saves a pretend key, uses it, then forgets it, in a throwaway place. No real key is used.

Leaked a key? stuntkey panic openai walks you through cancelling it and making a new one.
