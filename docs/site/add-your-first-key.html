Add your first key

About a minute. You never type a key into a web page, and you never paste it into your AI chat.

  1. Install StuntKey.

    You need Python 3.10 or newer. In a terminal:

    pipx install stuntkey
  2. Do it all in one go.

    This looks for keys lying around, moves the ones it knows into your keychain, switches on the Claude Code safety check, plugs StuntKey into your AI apps (Claude Code for every folder) and tests it. It lists the plan and asks once. Every change keeps a backup.

    stuntkey setup
  3. Close and reopen your AI app.

    Close every window of Claude, then open it again, so it picks up the change.

  4. Add another key later.

    Copy the key on the service's own page, then run this. StuntKey names the service from the key, tests it and locks it in your keychain. Or type a name like open ai.

    stuntkey get
  5. Check it worked.

    One line, PASS or FAIL, and what to do next. For the full picture in green, yellow and red, run stuntkey status. If something is not green, stuntkey fix repairs what it can.

    stuntkey test

Want to see it work first? stuntkey try saves a pretend key, uses it, then forgets it, in a throwaway place. No real key is used.

Changed your mind? stuntkey undo puts back what setup, fix or get changed last.

Leaked a key? stuntkey panic openai walks you through cancelling it and making a new one.
