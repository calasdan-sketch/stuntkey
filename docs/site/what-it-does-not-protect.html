StuntKey / What it does not protect

What StuntKey does not protect

StuntKey lowers the risk of a leaked key. It does not remove it. Here, in plain words, is what it cannot do. You can read the same list in a terminal with stuntkey limits.

  1. It lowers the risk. It cannot make it zero.

    No independent security expert has reviewed StuntKey yet. It is beta software.

  2. It cannot stop an AI misusing a key it is allowed to use.

    If you let your AI read your GitHub, it can read everything that key can read. Give each key only the permissions it needs, on the service's own website.

  3. It does not protect you from a virus or a person already using your account.

    Anything running as you on this computer can open your keychain, edit the activity log and click the permission windows. For risky AI tools, use a separate Windows account.

  4. The Claude Code safety check is a guard, not a wall.

    It looks for known tricks, and a determined or sneaky command can still get past it. It cannot hide keys from what Claude reads with Read, Grep or web tools; those are only checked before they run.

  5. Other AI apps have no safety check.

    Cursor, Codex, Gemini and Claude Desktop have no place for one, so their file tools can read a .env file.

  6. It does not hide your data.

    Answers from a service go to your AI, and so to the AI company. Only the key is hidden, not the rest.

  7. A program started with stuntkey run holds the key.

    That program can print it. Only start programs you trust this way.

  8. It cannot catch every disguise.

    Hiding a key inside an answer (odd letter shapes, compressed or scrambled text) is checked on a best-effort basis.

  9. The clipboard and screen are not covered.

    While you copy a key, other programs or clipboard history may see it for a moment. Screenshots are not checked.

  10. The activity log shows accidents and casual edits, not a determined attacker.

    Someone using your account can rewrite it.

  11. It does not phone home.

    StuntKey sends nothing about you. It talks only to the services you call. stuntkey update-check --online is the one thing that looks outside, and only when you type it.
